# Security policy

Version 0.1.0 is a development build. Physical Windows/Android checks have covered accepted transfers in both directions, a receiver decline, cancellation, and a network interruption; the current language and selected-card changes still need a visual check. Discovery listings alone do not authenticate peers. Compare the security code on both devices before approving an unknown peer. Do not use this development build for sensitive files yet. See the [release security checklist](docs/RELEASE_SECURITY.md) for signing, scanning, and hash publication requirements.

Please report security issues privately to the repository maintainers through GitHub's private vulnerability reporting after publication. Until then, contact the project owner privately rather than opening a public issue with exploit details. Include affected version, impact, and reproduction steps. We will acknowledge reports and coordinate a fix before disclosure.
